# mf_alert — カード引き落としの残高不足チェック

マネーフォワードの「口座」画面を全選択コピー（Ctrl+A → Ctrl+C）したテキストから、
カードの引き落とし予定（`-nn,nnn円` + `引き落とし日:(yyyy/mm/dd)`）を拾い、
引き落とし口座の残高が足りるかを判定する。標準ライブラリのみで動く。

## 準備
```sh
cp mf_alert.ini.example mf_alert.ini   # カード名 = 引き落とし銀行名 を実情に合わせて編集
```

## 実行
```sh
pbpaste | python3 mf_check.py           # Mac: コピー直後にそのまま
python3 mf_check.py paste.txt --notify  # ファイルから。不足時は通知センターにも表示
```
終了コード: 0=不足なし / 1=不足あり / 2=入力・設定エラー（シェルや cron から分岐に使える）

## 判定ロジック
- 今日〜`days_ahead` 日先の引き落としを、口座ごとに日付順で累計し、`累計 + margin > 残高` になった時点を「不足」とする
- 同じ銀行から複数カードが落ちる場合は合算される
- 次は「注意」として出す: 引き落とし額未確定のカード / ini に口座未登録のカード /
  銀行のステータスが正常でない・取得日時が古い（残高が当てにならない）/
  残高の取得が引き落とし日以降（引き落とし済みで二重計上の可能性）
